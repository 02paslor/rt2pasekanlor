Cara Pasang API Key AI

1. Buka situs aistudio.google.com

2. Login pakai akun Google Anda.

3. Klik menu "Get API Key" atau "Create API Key".

4. Salin kode (copy) yang diberikan.

5. Buka file kode web ini, cari baris atas:
const apiKey = "PASTE_DISINI";

6. Paste dan Simpan (Deploy ulang).
